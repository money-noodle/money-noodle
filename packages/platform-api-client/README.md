# Money Noodle platform API client

## Boundary

`packages/platform-api-client` is generated transport code for TypeScript interfaces. It contains request functions and wire models derived from the platform API's canonical OpenAPI document. It owns no domain rules, presentation state, authentication authority, secrets, or hand-maintained request implementation.

## Contract and generation

- Owner of source contract: `services/platform-api/openapi/platform-api.v1.yaml`.
- Generator: exactly pinned `@hey-api/openapi-ts` with Fetch client, TypeScript, and SDK plugins.
- Fetch transport: generated by the client plugin bundled with the pinned generator; no separate deprecated client package is installed.
- Generated path: `src/generated`; never edit it manually.
- Compiler boundary: `exactOptionalPropertyTypes` is disabled only for this generated transport package because generator 0.99 emits explicit `undefined` for optional Fetch fields; API/domain projects retain the stricter repository default.
- Published/build output: `dist` (private workspace package for now).
- Data/schema ownership: transport schemas only; no database schema.

Run from the repository root:

```bash
pnpm nx run platform-api-client:generate
pnpm nx run platform-api-client:lint
pnpm nx run platform-api-client:typecheck
pnpm nx run platform-api-client:test
pnpm nx run platform-api-client:build
pnpm nx run platform-api:contract
```

The contract check regenerates into a temporary directory and compares bytes, so stale or nondeterministic generated output fails without relying on the Git staging state.
