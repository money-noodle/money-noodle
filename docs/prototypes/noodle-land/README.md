# Noodle Land visual prototypes

Exploratory graphics and motion samples for the agreed Noodle Land direction. These are standalone prototypes,
not application routes or implementations of product requirements.

## View the current Brilliant Broths naming pass

```bash
open docs/prototypes/noodle-land/index.html
```

This pass keeps friendly pearl-onion Nomi, the improved Great Noodle Scale, three-stage Noodle Party, theme
support, and colorful evidence categories while refining progression language.

## Brilliant Broths

Each evidence category now has an alliterative title and four related sublevels. Puns are used when they stay
clear rather than becoming a decoding exercise.

| Broth category | Category title | Four sublevels |
| --- | --- | --- |
| Fresh Somen | Somen Seeker | Somen Starter · Somen Sifter · Somen Solver · Somen Sage |
| Tinker Udon | Udon Unraveler | Udon Know Yet · Udon Unraveler · Udon Updater · Ultimate Udon |
| Signal Soba | Soba Signal Scout | Soba Spotter · Soba Sorter · Soba Synthesizer · Soba Seer |
| Evidelli | Evidence Explorer | Evidelli Explorer · Evidelli Examiner · Evidelli Evaluator · Evidelli Expert |
| Calibramen | Calibration Cook | Calibramen Collector · Calibramen Counter · Calibramen Corrector · Calibramen Connoisseur |
| Bayes-Biang | Belief Balancer | Bayes Beginner · Broth Bayesian · Belief Balancer · Bayesically Brilliant |
| Infinite Noodlini | Null Navigator | Null Noodler · Noodlini Noticer · Null Navigator · Noodlini & Beyond |

The increasingly saturated aqua, green, gold, coral, lilac, orange, and pink shades remain category progression
decoration only—never financial outcome, readiness, track, or authority to trade.

## Retained systems

- **Great Noodle Scale:** Nomi pivot, gold noodle beam, low leaf-rimmed bowls, horizontal moving labels.
- **Noodle Party:** 72 outlined ribbons in a radial burst, orbital curl, and viewport-wide noodle rain.
- **Themes:** light by default with dark parity across the immersive surfaces.
- **Friendly Nomi:** pearl-onion face with pose-specific noodles, leaves, posture, and orbit.

The demo has no network requests, packages, durable state, app imports, trading data, or execution authority.
All balances and events are labelled sample paper values.
